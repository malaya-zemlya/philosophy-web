What separates the concepts of Newtonian mechanics from a trivially universal concept is not
abstractness, for mass is as abstract as information, but the possibility of failure. Newton's
second law, with forces given by independent force laws, forbids some trajectories and fails for
very fast or very small systems. Its quantities are fixed by measurement procedures (a balance for
mass, a ruler for position) settled before the case is examined, and the mapping is then tested on
cases it was not fitted to, including counterfactual ones. Trivializing constructions, such as
Putnam's mapping of a rock's states onto an arbitrary automaton ([putnam-1988](../sources/putnam-1988.md)), choose the
mapping after seeing the system, separately for each case, so that the mapping carries all the
information and the model none. The counterfactual constraint on implementation
([implementation-requires-counterfactual-structure](implementation-requires-counterfactual-structure.md)) is one application of the test.

A compression criterion, on which a real pattern is a description much shorter than the data
([Dennett, 1991](../sources/dennett-1991b.md)), is equivalent only if it is two-part: the length of the model
plus the length of the residual errors, for a target variable and error tolerance fixed in advance,
must be much less than the raw data. Without the error term the criterion is vacuous, since every
lossy map compresses.

The test protects physics from triviality arguments. It does not settle which systems represent. A
photographic plate passes it: relative to light intensity at the plate's grain resolution, the latent
image reproduces the incident light within a stated error, and it records nothing about sound. So the
test rules out gerrymandered attributions, not genuine information-carrying.

### In plain terms

Any good scientific idea must be able to be wrong about something. "Has mass and obeys Newton's laws"
is false of some things, and you can check it by procedures fixed in advance. An idea you can make
true of anything by choosing how to read the system after you have looked at it is not doing any
work. This test keeps physics safe from that kind of trick, but a camera film still passes it.
