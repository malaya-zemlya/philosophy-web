A sufficiently capable knower can simulate itself, and a full, counterfactually faithful functional
simulation of an agent seeing red is, on a strong functionalist view, an agent that knows what red is
like. But the knowing then belongs to the simulated agent. The one running the simulation knows,
in full detail, what state it would be in, without being in that state ([beaton-2005](../sources/beaton-2005.md),
pp. 19–20). Michael Beaton accepts the functionalism and the simulation and denies only that the
simulator inherits what the simulation has.

In the terms of [self-access-kinds](../concepts/self-access-kinds.md), the claim separates *simulating* oneself from
*writing* to oneself. To get from the simulated state into its own state, the agent must either set
its own low-level colour system or connect the simulated one to its own reasoning, and both are acts
of self-modification.

### In plain terms

A robot could run a perfect copy of itself inside its computer and show the copy a red tomato. The
copy would then know what red looks like. The robot running it would know everything about the
copy's state, but it would not thereby be in that state itself.
