relevance (content): a review of the *temporal correlation* (synchrony) hypothesis, on which neurons
coding features of the same object are bound by firing in synchrony, with the experimental evidence
for stimulus-dependent synchronization in visual cortex. Cited in [binding-problem](../concepts/binding-problem.md).

Reference:
- Singer, W., & Gray, C. M. (1995). Visual feature integration and the temporal correlation
  hypothesis. *Annual Review of Neuroscience*, *18*, 555–586.
