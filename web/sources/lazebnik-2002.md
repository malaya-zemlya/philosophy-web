relevance (method): argues, by imagining biologists using their standard methods to fix a broken
radio, that cataloguing components and correlations does not yield an understanding of how a system
works without a formal, engineering-style description of it. Used by [mikhailov-2024](mikhailov-2024.md) as
an analogy for the neural-correlates programme in [ncc-programme-lacks-causal-hypotheses](../claims/ncc-programme-lacks-causal-hypotheses.md).

Reference:
- Lazebnik, Y. (2002). Can a biologist fix a radio?—Or, what I learned while studying apoptosis.
  *Cancer Cell*, *2*(3), 179–182. https://doi.org/10.1016/S1535-6108(02)00133-2
