# Notes: where the discussion of "The Unwarrantable Premise" ended up

*2026-11-20. Working notes only; none of the citations below have been verified against the original works.*

The original paper's computability core (halting-problem reduction, D1/D2/D3 trilemma) was found not to
carry the argument (see [the-unwarrantable-premise-review.md](the-unwarrantable-premise-review.md)). The discussion produced three
separable lines instead.

## Definitions

- $P$: the complete true (ideal) physics, so consistent. $C$: someone is conscious. $Z = P \wedge \neg C$.
- $A$: the a priori truths, closed under consequence.
- **IC** (negative ideal conceivability): $\mathrm{IC}(S) \iff A \nvdash \neg S \iff \mathrm{Con}(A \cup \{S\})$.
  So T1 is exactly $\mathrm{Con}(Z \cup A)$; it entails plain $\mathrm{Con}(Z)$ but not conversely
  (married bachelor).
- **A priori bridge principle**: a sentence of $A$ linking phenomenal and physical vocabulary, i.e. one not
  following from the pure sentences of $A$. Not Nagel's (empirical) bridge laws, and not the dualist's
  contingent psychophysical laws (the paper's line 32 uses "bridging principles" in that other sense; rename).
- With no bridge principles, Robinson's joint consistency theorem gives $\mathrm{Con}(Z \cup A)$, modulo
  disagreement on pure-logic sentences (e.g. cardinality).

## Paper A: many arguments, one premise (the main target)

Stripped down, the zombie argument is *conceptual isolation + CP*. Either bridge principles exist, and T1
is an uncertified consistency conjecture (cf. Russell's paradox, Malliaris & Shelah's 𝔭 = 𝔱), which
mathematics would state only relatively; or they don't, and T1 is trivial chess-style independence that
carries force only if phenomenal truths are also concrete truths about physical beings. In slogan form:
"if zombies can exist then physicalism is false", or "independent things are independent".

Thesis: the apparatus Chalmers builds around T1 double-counts one premise. Inventory, each item to be
shown to restate isolation, share its intuition, or be conjecture-level:

| Item | Verdict |
|---|---|
| Structure-and-dynamics argument | restates isolation (S3 ≈ T1 given S1, S2) |
| Knowledge argument (Mary) | the same non-derivability in epistemic dress; needs the most care |
| Inverted spectrum | another conceivability claim of the same kind |
| Homunculus-head case | the same intuition |
| Epistemic asymmetry | a description of isolation, not evidence for it |
| Absence of analysis | induction from failures, conjecture-level |
| Ideal vs prima facie | immunity bought by making T1 uncertifiable |

Fairness constraint: 2D semantics and primary/secondary conceivability defend **CP** against type-B
physicalists. Set them aside explicitly as addressing a different opponent; attack only the T1 apparatus.

## Paper B (separate): can isolated phenomenal facts be argued about?

Public argument is physical; zombie Chalmers writes the same book. A link from phenomenal facts to our
discourse is a priori (a bridge), causal (idle in the zombie world), or acquaintance. All exhibitable
acquaintance (seeing Paris, riding a bike) is ordinary causal knowledge the zombie shares; the special
kind cannot enter a shared premise. Prior art: Chalmers's paradox of phenomenal judgment (1996, ch. 5;
web: `concept-paradox-of-phenomenal-judgment`), Kirk 2005/2008 (epistemic contact), Thomas 1996. Main risk:
the SEP *Zombies* entry calls private-language-style objections question-begging; the defence must derive
public checkability from the argument's being offered publicly, not assume it.

## Possible note (separate): transmission failure

Once CP is granted, the only movable audience is the type-A physicalist, for whom T1 is no more evident than
the conclusion. The zombie argument as a Moore's proof for dualists (Wright on transmission failure; web:
`argument-moore-proof-begs-the-question`).
