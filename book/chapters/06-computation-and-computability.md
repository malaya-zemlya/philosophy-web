The previous chapter asks whether the right functional organisation is enough for a mind. This chapter
asks the same question about computation, and about the limits of what can be computed. Its central
tool is the [halting-oracle](../../web/concepts/halting-oracle.md), a device that would decide whether any program halts and that
Turing proved no computer can be. Several arguments in the book quietly assume capacities of this
kind. The entries here argue that some scenarios can be conceived only because the conceiver has not
noticed that they require an oracle, and that certifying an ideal reasoner's consistency is itself
oracle-hard.

Roger Penrose argues that human understanding is non-computational, so consciousness cannot be a
computation. The chapter then takes up Maudlin's Olympia, a machine built to run a single computation
while doing almost no physical work. Olympia is meant to show that computational functionalism
assigns consciousness to systems whose physical activity cannot plausibly matter. The replies
consider whether Olympia really implements the computation, whether recording a run is the same as
running it, and what quantum counterfactuals would change.
